# SecMinds Solutions design system (vendored)

`tokens.css`, `bundle.css`, `bundle.js` and `components.d.ts` are copied unchanged from the SecMinds Solutions design system (`project/tokens.css` and `project/components/`). Do not edit them here; replace them with a newer copy from the design system instead.

`react-global.ts` and `index.ts` adapt the bundle to this app: the bundle reads React from `window.React` and publishes its components on `window.SecMinds`.
