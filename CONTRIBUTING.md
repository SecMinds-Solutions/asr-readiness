# Contributing

Thanks for your interest in ASR Compas.

This repository is published from SecMinds' development repository, so pull requests
here cannot be merged and are closed automatically. Contributions are very welcome as
issues:

- **Bug reports:** what you did, what you expected and what happened. Never include
  tenant IDs, device names, file paths from your environment or other security data.
- **Ideas and feedback:** open an issue describing the problem you want solved.

The domain language is in [`CONTEXT.md`](CONTEXT.md) and the design decisions are in
[`docs/adr/`](docs/adr/).

## Security issues

Do not open a public issue for a vulnerability. Report it privately through GitHub's
"Report a vulnerability" option on the Security tab of this repository.
